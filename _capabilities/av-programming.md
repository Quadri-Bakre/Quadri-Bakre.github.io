## How I approach it
1. **Start from how the client lives.** Rooms, scenes and controls are set up around how the space is actually used.
2. **Build on a solid network.** Control processors, panels and AV-over-IP devices get fixed addresses and the right VLAN before any programming starts.
3. **Program, then test every function.** Every scene, source and room is checked on the touch panels, keypads and app the client will use.
4. **Integrate, don't bolt on.** Lighting, heating and AV are brought into one interface so the client has one way to control the home.

## Why I work this way
Most programming problems turn out to be network problems: a device that drops off, an address that changes, multicast that floods a switch. Getting the foundations right first means the programming stays reliable after handover, and the client gets a system that behaves the same way every day. I've also tested myself in Crestron's Home Programming Challenge at ISE in Barcelona.

## Tools I use
Crestron Home Setup, Crestron Toolbox, Crestron Construct, Control4 Composer Pro, Loxone Config, Lutron programming software, Dante Controller.
