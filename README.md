# quadribakre.com

Source for my portfolio site, built with [Jekyll](https://jekyllrb.com) and published with GitHub Pages.

## Where things live

| What | Where |
|---|---|
| Name, email, footer details | `_data/profile.yml` |
| Menu links | `_data/navigation.yml` |
| Social links | `_data/social.yml` |
| Case studies (one file each) | `_projects/` |
| Page layouts | `_layouts/` |
| Shared pieces (menu, footer) | `_includes/` |
| Styles | `assets/css/style.css` |
| Images | `assets/images/` |

## Preview locally

```
bundle install
bundle exec jekyll serve
```

Then open http://127.0.0.1:4000.
